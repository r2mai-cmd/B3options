B3OPTIONS — SIMULADOR DE ESTRATÉGIAS

1) Coloque simulador.html dentro de docs/ no GitHub Pages.
2) Se quiser manter sua calculadora B&S atual, não substitua calculadora-bs.html.
3) No menu do seu docs/index.html, acrescente:
   <a href="simulador.html">Simulador</a>

Se quiser também usar o exemplo de calculadora B&S deste pacote:
   <a href="calculadora-bs.html">Calculadora B&S ↗</a>

O simulador é independente, não usa React/npm e funciona no GitHub Pages.
Ele permite:
- CALL e PUT
- Compra e Venda
- Quantidade
- Strike e prêmio
- Preço atual
- Volatilidade e taxa
- Vencimento
- Gráfico de P&L no vencimento e antes do vencimento
- P&L atual, máximo/mínimo e pontos de equilíbrio

IMPORTANTE:
O simulador é uma ferramenta educacional/demonstrativa. Não é recomendação de investimento.
