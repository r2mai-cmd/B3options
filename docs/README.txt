B3Options — arquivos para substituição

Alterações desta versão:
- Calculadora B&S com entrada/exibição em notação brasileira (vírgula decimal).
- Simulador com botão + ATIVO.
- Lista de ativos no parâmetro da estratégia.
- Seleção de vencimentos semanais.
- Seleção de CALL/PUT com strikes sugeridos conforme o ativo.
- Código da série preenchido automaticamente a partir de tipo/strike.
- Preços/prêmios em notação brasileira.
- ATIVO entra no payoff/P&L como uma perna da estratégia.

Observação:
Os dados de mercado deste projeto continuam demonstrativos. Os códigos de opções sugeridos são gerados para a interface e não representam uma consulta em tempo real à B3.
